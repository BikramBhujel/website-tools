IPv4 Subnet Calculator

Calculate CIDR networks, subnet masks, wildcard masks, broadcast addresses and usable host ranges directly in your browser. No API, iframe or external calculator is used.

Network input

Enter an IPv4 address and CIDR prefix. You can also type CIDR notation directly, for example 192.168.10.25/24.

Calculation is performed locally in your browser. IPv4 addresses entered here are not submitted to the website backend.

Subnet details

Results use standard IPv4 CIDR semantics, including RFC 3021 handling for /31 point-to-point networks.

Enter an IPv4 address and CIDR prefix to calculate the network.
